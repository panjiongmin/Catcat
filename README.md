# 猫猫小街 Catcat

经营自己的猫咪小街：三花、缅因、狸花在街上溜达，点猫可以撸猫、喂食、逗猫。猫全部用代码画（1 号脸型、粗描边平涂），性格同时决定五官和走路方式。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev      # 开发服务器，终端会打印本机和局域网地址，手机连同一个 Wi-Fi 也能打开
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览打包结果
```

## 操作

- 拖动街道左右移动，滚轮或双指缩放
- 点猫或底部头像：查看状态，撸猫 / 喂食 / 逗猫
- 点建筑、纸箱：查看信息
- 电脑上：方向键或 A / D 平移，+ / − 缩放，Esc 关闭面板

## 目录

```
src/
  cats/catkit.js     代码猫引擎：身体、腿、尾巴、脸，动作片段（待机 / 走 / 小跑 / 潜行 / 跳 / 转身）
  world/             小街：场景（SVG 两层）、摄像机、街上的猫（Canvas）
  game/              数据与数值规则
  ui/                顶栏、面板、底部头像栏
```

街道是两层 SVG，中间夹一层 Canvas 画猫：建筑和树在猫后面，路灯在猫前面。
