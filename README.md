# 猫猫小街 Catcat

经营自己的猫咪小街：三花、缅因、狸花在街上溜达，点猫可以撸猫、喂食、逗猫。猫全部用代码画（1 号脸型、粗描边平涂），性格同时决定五官和走路方式。

## 本地运行

需要 Node.js 22 或更新版本（wrangler 4 的要求；用 nvm 的话：`nvm install 22` 然后 `nvm use 22`）。

```bash
npm install
npm run dev      # 游戏（Vite）+ 小街服务器（wrangler dev，8787 端口）一起启动
npm run dev:web  # 只开游戏，不开服务器：自动进入单机模式
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 打包后用 wrangler 在本机跑一遍正式版
```

终端会打印本机和局域网地址，手机连同一个 Wi-Fi 也能打开。本地服务器的数据存在 `.wrangler/` 里，删掉这个文件夹就是全新的服务器。

## 部署到 Cloudflare

游戏和服务器是同一个 Worker：静态文件来自 `dist/`，`/api/*` 交给服务器。

```bash
npx wrangler login   # 第一次：浏览器里登录你的 Cloudflare 账号
npm run deploy       # 打包并发布到 https://cat.887756.xyz
```

用到 Durable Objects（SQLite 版），Workers 免费套餐就能用，不需要建数据库。

域名写在 `wrangler.jsonc` 的 `routes` 里：`887756.xyz` 要在同一个 Cloudflare 账号下，`cat` 这个子域名事先不能有 DNS 记录，发布时会自动建好。

## 多人同屏

- 每个人第一次打开会自动拿到一个匿名账号和一条自己的小街，原来存在本机的猫会一起带上去
- 顶栏「街坊」里能看到这条街住着谁、谁在线，复制邀请链接发给朋友；朋友打开链接确认后，带着自己的猫搬过来
- 一条街最多 4 户，每户最多 6 只猫；一个人同时只住一条街
- 别人的猫：能撸（算进它每小时 5 次的上限）、能喂（花自己的猫币）；逗猫、洗澡只有主人能做。主人会收到提示「某某摸了摸你的花卷」
- 猫的属性在服务器上按服务器时间结算，主人不在线时猫也一直在街上
- 街上的猫怎么走由一个“带路人”页面决定（最早打开、并且正在看的那个），服务器把它的指令转发给所有人，所以大家看到的是同一只猫在做同一件事；带路人关掉页面会自动换人
- 「存档码」是 6 位字母数字，换设备或清了浏览器数据时用它找回自己的猫
- 连不上服务器时自动进入单机模式，存档留在本机

## 操作

- 拖动街道左右移动，滚轮或双指缩放
- 点猫或底部头像：查看状态，撸猫 / 喂食 / 逗猫
- 点建筑、纸箱：查看信息
- 电脑上：方向键或 A / D 平移，+ / − 缩放，Esc 关闭面板
- 按现实时间结算；离开超过 5 分钟回来会弹“欢迎回来”
- 单机模式下地址后面加 `?reset` 可以清空本机存档重新开始

## 目录

```
src/
  cats/catkit.js     代码猫引擎：身体、腿、尾巴、脸，动作片段（待机 / 走 / 小跑 / 潜行 / 跳 / 转身 / 坐 / 睡 / 吃 / 被摸）
  world/             小街：场景（SVG 两层）、摄像机、街上的猫（Canvas）
  game/              数据、数值规则（rules.ts，服务器也用同一份）、存档与现实时间结算（save.ts）
  net/               和服务器之间的消息格式（protocol.ts）、连接与重连（online.ts）
  ui/                顶栏、面板、底部头像栏、街坊卡片
server/
  index.ts           Worker 入口：/api/hello、login、join、rename、ws
  accounts.ts        账号（Durable Object）：token、存档码、住在哪条街
  street.ts          一条街一个 Durable Object：住户、猫、属性结算、WebSocket 广播
```

街道是两层 SVG，中间夹一层 Canvas 画猫：建筑和树在猫后面，路灯在猫前面。
